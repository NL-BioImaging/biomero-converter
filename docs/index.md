# biomero-converter

Conversion from various formats to Ome-tiff and Ome-zarr

## Ways to use it

- **Desktop application:** `pip install "biomero-converter[gui]"`, then run `biomero-converter-gui`; see [Desktop GUI](gui.md).
- **Command line or Docker:** `biomero-converter --inputfile ... --outputfolder ...`; see [Run the Main Script](main.md).
- **Python:** `from biomero_converter.converter import convert`; see [Convert](convert.md).
- **BIOMERO:** as the preprocessing container for imports; see [Container requirements](container.md).
